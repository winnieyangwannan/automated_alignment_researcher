# Automated Alignment Researcher with AutoData

This project is built on the original Anthropic Automated Alignment Researcher
(AAR) [codebase](https://github.com/YuehHanChen/automated_alignment_researcher) and extends it with support for multi-axis alignment optimization
and automated synthetic-data generation.

## New functionality

1. **Multi-axis alignment optimization** — optimize multiple alignment axes
   simultaneously within a single research and training workflow.
2. **AutoData integration** — automatically generate high-quality synthetic
   data for training (autodata code is [here](https://github.com/fairinternal/autodata_pipelines/tree/main)).
